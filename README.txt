Download the official UCI Polish Companies Bankruptcy dataset from https://www.archive.ics.uci.edu/dataset/365/polish%2Bcompanies%2Bbankruptcy%2Bdata (Download, 8.4 MB). Extract the archive and copy 3year.arff into this data folder. Restart the app; it will load this local file without contacting the UCI API. Source: Tomczak (2016), UCI Machine Learning Repository, DOI: 10.24432/C5F600.
